FOIL LAYER Print Specifications

What This File Contains

  • Page 1: Front foil placement (logo and text)
  • Page 2: Back foil placement (contact info and QR code)
  • Background: White (for visibility only - NOT printed)
  • Black Elements: K=100 pure black indicating silver foil placement

How Printers Use This File

  • Black areas show where to apply silver foil stamping
  • White background is ignored - actual cards use black cardstock
  • This layer MUST align precisely with the COLOR layer
  • Foil is applied AFTER soft-touch lamination

Dimensions (Same as Color Layer)

  • Finished Size: 3.5" × 2" (standard business card)
  • With Bleed: 3.75" × 2.25" (0.125" bleed all sides)
  • Safe Zone: 3.25" × 1.75" (keep text/logo inside)

Foil Specifications

  • Foil Type: Hot stamped silver foil
  • Coverage: All text, logo, and QR code
  • Application: After soft-touch lamination
  • Registration: Must align precisely with color layer

Files to Submit to Printer

  • Companion file (COLOR): business-card-front-color.pdf + business-card-back-color.pdf
  • This file (FOIL): business-card-front-foil.pdf + business-card-back-foil.pdf
  • Spec sheet: PRINT_SPECIFICATIONS.txt

Instructions for Printer

"Black elements in foil layer PDFs indicate silver foil placement. Apply hot stamped silver foil to all K=100 black areas shown. Foil should be applied after soft-touch lamination. Ensure precise registration with color layer."

Pre-Flight Checklist

  • ✓ All elements shown in K=100 pure black
  • ✓ Background is white (for visibility)
  • ✓ Dimensions match color layer exactly (3.75" × 2.25")
  • ✓ All fonts converted to outlines
  • ✓ Images embedded (not linked)
  • ✓ Registration marks aligned with color layer
  • ✓ PDF/X-1a:2001 compliant (recommended)
