Back Foil Element - MOO Upload

Single-page file for MOO's "Back" section → "Upload Silver Foil Element" button

  1. Open this file in Chrome or Firefox
  2. Print to PDF (Press Quality)
  3. Ensure "Backgrounds" option is checked
  4. Set margins to "None"
  5. Upload to MOO: Back section → Upload Silver Foil Element

NOTE: Black elements (K=100) indicate where silver foil will be applied. White background is for visibility only.
