DIMENSIONS
----------
Finished Size: 3.5" × 2.0" (standard business card)
Trim Size: 3.5" × 2.0"
Bleed Area: 3.75" × 2.25" (0.125" bleed on all sides)
Safe Zone: 3.25" × 1.75" (0.125" margin from trim)

MATERIAL SPECIFICATIONS
-----------------------
Cardstock: 16pt black uncoated cardstock
Lamination: 1.5mil soft-touch/velvet matte coating (both sides)
Total Thickness: ~19pt finished
Finish: Matte soft-touch lamination with silver foil stamping

COLOR SPECIFICATIONS
--------------------
Color Space: CMYK
Background Color: Rich Black (40C / 30M / 30Y / 100K)
Foil Color: Silver (hot stamped)
Resolution: 300 DPI minimum
File Format: PDF/X-1a:2001 or Press-Ready PDF

FOIL STAMPING DETAILS
---------------------
Foil Type: Hot stamped silver foil
Foil Application: All text elements and logo
Foil File: Separate K=100 (pure black) layer indicating foil placement
Foil Coverage: Logo, all text on front and back
Special Notes: Logo is circular design with transparent background

TYPOGRAPHY
----------
Primary Font: Helvetica Neue
Letter Spacing: 110-120% (optimized for reversed type on dark background)
Font Handling: All fonts must be converted to outlines/paths
Minimum Font Size: 9pt

FILE DELIVERY REQUIREMENTS
---------------------------
Files to Submit:
1. Main Color File: business-card-front-color.pdf (with bleed)
2. Main Color File: business-card-back-color.pdf (with bleed)
3. Foil Layer File: business-card-front-foil.pdf (K=100 black only)
4. Foil Layer File: business-card-back-foil.pdf (K=100 black only)
5. This specification document

File Requirements:
- PDF format (PDF/X-1a:2001 preferred)
- CMYK color space only (no RGB or spot colors except foil layer)
- All fonts converted to outlines/paths
- All images embedded (not linked)
- Compression: None or lossless only
- 300 DPI minimum resolution for all elements
- Bleed extended 0.125" on all sides
- Crop marks and registration marks optional
